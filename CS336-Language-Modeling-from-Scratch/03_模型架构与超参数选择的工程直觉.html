第三讲：模型架构与超参数选择的工程直觉

把 Transformer 拆成四个可以逐一手写的模块：归一化、位置编码、注意力、前馈网络

主讲：Tatsunori Hashimoto（斯坦福大学计算机系助理教授）
对应真实课程材料：Lecture 3 讲稿、Assignment 1（Basics）Section 3.3-3.5

一、 Pre-Norm 与 Post-Norm：一个看似很小、实际很关键的顺序调整

原始的 Transformer 论文（Vaswani et al., 2017）在每个子层（自注意力、前馈网络）之后做层归一化（LayerNorm），这被称为"Post-Norm"结构。后续研究发现，把归一化挪到每个子层的输入端，并在最后一个 Transformer block 之后再补一次归一化，训练会更稳定。这就是"Pre-Norm"结构，也是 GPT-3、LLaMA、PaLM 等现代语言模型的标准做法，CS336 的作业要求实现的也是这个版本。

为什么 Pre-Norm 更稳定？直观的解释是：Pre-Norm 让"残差流"（residual stream，也就是从输入嵌入一路加到最终输出的那条主干路径）不经过任何归一化操作，保持数值上的干净和连续，这样梯度在反向传播时能更顺畅地流回浅层，不会被中间的归一化操作打断或扭曲。一个 Pre-Norm 子层的更新公式是：

$$y = x + \text{MultiHeadSelfAttention}(\text{RMSNorm}(x))$$

也就是说，输入 $x$ 先归一化，再送进注意力模块，最后把注意力的输出加回原始的 $x$（而不是加回归一化之后的值）。这个"加回原始输入"的操作就是残差连接（residual connection），它保证了信息和梯度都有一条不被中间层改变的"直达通道"。

二、 RMSNorm：比原版 LayerNorm 更省一步计算的归一化方式

归一化的作用是把每一层的输出重新缩放到一个稳定的数值范围内，防止训练过程中数值越滚越大或越滚越小。原始 Transformer 用的是 LayerNorm，CS336（跟随 LLaMA 等模型）改用 RMSNorm（Root Mean Square Layer Normalization）。它和 LayerNorm 的核心区别是：LayerNorm 要同时减去均值、除以标准差两步操作，RMSNorm 只做"除以均方根"这一步，去掉了减均值这一步：

$$\text{RMSNorm}(a_i) = \frac{a_i}{\text{RMS}(a)}\, g_i, \qquad \text{RMS}(a) = \sqrt{\frac{1}{d_{\text{model}}}\sum_{i=1}^{d_{\text{model}}} a_i^2 + \varepsilon}$$

其中 $g_i$ 是模型自己学出来的缩放参数（每个维度一个），$\varepsilon$（常取 $10^{-5}$）只是为了防止除以 0。作业里有一个很实用的实现细节：计算时要先把输入从半精度（如 float16/bfloat16）转成 float32，算完再转回原精度，因为对激活值求平方（$a_i^2$）很容易在低精度下发生数值溢出，这是训练大模型时一个真实会踩到的坑。

三、 RoPE：把"位置"编码成一次旋转，而不是一个加上去的向量

自注意力机制本身对序列顺序不敏感，如果不额外提供位置信息，"猫追狗"和"狗追猫"在模型看来输入的是同一组无序的词。早期 Transformer 用的是"正弦位置编码"，把一个和位置相关的向量直接加到词向量上。CS336 采用的是更现代的方案：旋转位置编码（Rotary Position Embedding, RoPE）。

RoPE 不是"加一个位置向量"，而是对 Query 和 Key 向量做一次和位置相关的旋转。具体来说，给定位置 $i$ 上的 Query 向量 $q^{(i)}$，RoPE 把它的每一对相邻维度看作一个二维向量，按角度 $\theta_{i,k} = i / \Theta^{(2k-2)/d}$ 做旋转：

$$R_i^k = \begin{pmatrix} \cos\theta_{i,k} & -\sin\theta_{i,k} \\ \sin\theta_{i,k} & \cos\theta_{i,k} \end{pmatrix}$$

这样设计的好处是：两个 token 之间的注意力分数，最终只依赖于它们位置之差，而不是各自的绝对位置。这正是"旋转"的数学性质保证的（两个向量各自旋转后再做内积，结果只和旋转角度之差有关）。这个性质让模型在处理比训练时见过的更长的序列时，也能保持相对稳定的位置感知，这也是 RoPE 被 LLaMA、GPT-NeoX 等现代模型广泛采用的原因。工程上有一个重要的效率优化：$\cos$、$\sin$ 的值只和位置、维度有关，和具体是哪一层、哪一个 batch 无关，所以可以只算一次、缓存下来，在所有层之间复用（作业建议用 register_buffer(persistent=False) 存这份缓存，因为它不是需要学习的参数）。RoPE 只作用于 Query 和 Key，不作用于 Value，而且是全局唯一的一份计算，没有自己的可学习参数。

四、 缩放点积注意力与因果掩码：模型如何"回头看"，又如何被禁止"偷看未来"

自注意力的核心公式是：

$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

直白地说：$QK^\top$ 算出每个位置对其他所有位置的"相关性打分"，除以 $\sqrt{d_k}$ 是为了防止维度变大后打分数值过大导致 softmax 梯度消失，softmax 把打分转换成一组加起来等于 1 的权重，最后用这组权重对 $V$ 做加权平均，得到这个位置"综合了整个序列信息之后"的新表示。softmax 本身的实现也有一个数值稳定性技巧：直接对分数取指数容易在数值上溢出（$e^{大数}$ 会变成 inf），标准做法是先减去这一行里的最大值再取指数，因为 softmax 对整体加减一个常数是不变的，这样能保证最大值对应的指数结果正好是 $e^0=1$，不会溢出。

语言模型还需要一个额外限制：预测第 $i$ 个词时，模型只能看到第 $1$ 到第 $i$ 个词，绝对不能"偷看"后面还没生成的词。这在生成阶段是必然的（未来的词还不存在），如果训练时不加限制，模型会学会一个在真实推理时用不了的"作弊"策略。这个限制通过因果掩码（causal mask）实现：把注意力打分矩阵中"位置 $i$ 看位置 $j$（其中 $j>i$）"对应的位置加上负无穷，softmax 之后这些位置的权重自然变成 0，信息就被彻底切断了。

多头注意力（Multi-Head Attention）则是把这一整套操作并行做 $h$ 次，每一"头"用的是 Query/Key/Value 各自维度上切出来的一小片（$d_k=d_v=d_{\text{model}}/h$），各自独立计算完再拼接起来：

$$\text{MultiHeadSelfAttention}(x) = W_O\, \text{Concat}(\text{head}_1,\dots,\text{head}_h)$$

为什么要切成多头而不是用一个大头？直观理解是：不同的头可以在训练中各自专注于不同类型的关系（比如有的头倾向于捕捉相邻词的语法关系，有的头倾向于捕捉长距离的指代关系），多头给了模型在同一层内并行探索多种关注模式的空间，而不是被迫用一种打分方式覆盖所有情况。

五、 SwiGLU 前馈网络：用"门控"替代普通的 ReLU 两层全连接

每个 Transformer block 里，注意力子层之后是一个前馈网络（FFN）。原始论文用的是两层线性变换夹一个 ReLU 激活。CS336（跟随 LLaMA、Qwen 等现代模型）改用 SwiGLU：把 SiLU 激活函数（也叫 Swish，定义为 $\text{SiLU}(x) = x \cdot \sigma(x)$，形状和 ReLU 相似但在 0 附近是平滑的，没有 ReLU 那种生硬的拐点）和一个"门控"机制结合起来：

$$\text{FFN}(x) = W_2\big(\text{SiLU}(W_1 x) \odot W_3 x\big)$$

这里 $W_1x$ 和 $W_3x$ 是两个独立的线性变换，$\odot$ 是逐元素相乘。直观理解：$\text{SiLU}(W_1x)$ 起到"门"的作用，决定 $W_3x$ 里的每个维度应该被放行多少、抑制多少。这种门控结构被认为能提供一条更干净的梯度传播路径，缓解深层网络的梯度消失问题。作业里给出的隐藏层维度经验设置是 $d_{ff} = \frac{8}{3} d_{\text{model}}$（不是原始论文常见的 4 倍，因为多了一组权重矩阵 $W_3$，为了保持总参数量大致不变而按比例调低），并取最接近的 64 的倍数以提升硬件计算效率。为什么是 SwiGLU 而不是别的激活函数组合？作业里引用了提出这一架构的论文里一句很诚实的话，"我们无法解释为什么这些架构会有效，我们将它们的成功归因于神的恩典"，也就是说，这更多是经验实验反复验证出来的最优选择，而不是能从第一性原理严格推导出来的结论。
