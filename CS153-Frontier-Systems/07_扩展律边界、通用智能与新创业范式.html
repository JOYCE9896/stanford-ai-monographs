第七讲：扩展律边界、通用智能与新创业范式

重访 CS183、ChatGPT 的意外诞生、卖电不如卖“夜光”与扩展律信徒的复仇

主讲导师：Sam Altman（OpenAI 联合创始人兼 CEO）
现场研读：Sam Altman 与斯坦福师生的激荡对谈

一、 十年重回 CS183：如果今天重开创业课，所有教条都得作废

当 Sam Altman 走入教室时，全场爆发出最热烈的欢呼。Midha 感慨道："2014 年我在斯坦福念本科时，对我这代人影响最深远的一门课就是 Sam 主讲的 CS183（How to Start a Startup）。今天你重回斯坦福讲台，是什么感觉？"

Altman 站在白板前，双手插兜："我走进来的时候就在想：如果我现在还有哪怕一点点空余时间，我最想做的事情就是把 CS183 彻底重写一遍。因为过去十年里我们奉为圭臬的创业常识，在今天几乎全都是错的！目前我还没看到市面上有任何人写出了一本合格的‘AI 时代创业新法则’。"

Altman 谈到了 YC 早期的一段隐秘认知：当年大家以为 YC 的价值在于合伙人的指导，但规模化之后才发现，真正的奇迹是**批次规模（Batch Size）扩大后在创业者之间自发涌现的内生网络效应**。这种只有在尺度突破临界点后才会出现的涌现属性，正是后来贯穿 OpenAI 整个技术信仰的根基。

二、 ChatGPT 的爆红真相：因为 API 没人用，开发者只想闲聊

随后，Altman 披露了整个人类商业史上最具戏剧性的产品诞生内幕：ChatGPT 的出现根本不是什么处心积虑的十年宏图，而是一场阴差阳错的被动救火。

"当年我们发布 GPT-3 和 3.5 的 API，试图向各大企业推销。结果极其尴尬：除了少数特定场景，绝大多数传统公司的开发团队根本不知道怎么把这个补全接口整合进现有业务流程，B 端集成一筹莫展。"Altman 坦言，"但我们在服务器后台监控到了一种极其诡异的开发者行为：很多工程师明明申请了商业 API 密钥，却根本不去写生产代码，而是自己偷偷写了个带输入框的 Python 小脚本，在终端里整天整夜跟模型瞎聊！"

OpenAI 团队敏锐地想起了 YC 最核心的一条铁律：去看看你的用户到底在狂热地爱着什么，然后顺从人性把它做成产品。

"当时我们其实已经把 GPT-4 训练完了，本来打算继续憋大招。但看到这个后台现象，我们决定暂缓一下，把一个小规模的对话微调版本套上一个最简陋的网页聊天框，作为‘研究预览版’（Research Preview）扔到了网上，这就是 ChatGPT。我们当时内部甚至觉得它可能火几天就会沉寂。"

结果接下来的五天彻底重写了历史：访问流量以竖直曲线狂飙，服务器连续熔断。第一天流量暴涨，第二天回落，外界评论说"看吧，不过是三分钟热度的泡沫"；但第三天峰值翻倍，第四天继续指数级攀升。"到了第五天，我心里彻底有数了——当一个产品在自身极度粗糙、经常崩溃报错的情况下依然把服务器撑爆，你就知道自己手里抓着一个改变人类文明的核武器了。"

三、 爱迪生卖电的历史暗号：别卖电，卖“夜间的光”

Altman 在讲座中引用了电力革命初期一段发人深省的技术史：

"十九世纪末发电机刚发明的时候，电力公司一开始尝试向大众推销‘电’本身。他们去街头打广告说‘电是宇宙中最神奇的能量，你可以买电回家’。结果根本没人买单，普通人只觉得那是一根会把人电死在浴缸里的恐怖铜线。"

爱迪生和早期的先驱很快意识到市场错位了：人类不需要理解发电机，不需要知道交流电直流电的物理学，人类真正渴望的是黑夜里的光明（Light at Night）！于是他们改卖灯泡和夜间照明系统，整个电力工业自此如野火燎原。

"今天的 AI 行业正处在完全相同的转折点。"Altman 指出，过去两年大家都在卖 Token、卖模型 API、卖算力卡，整个行业充斥着晦涩的浮点参数与上下文长度。"但最终能够吸纳数万亿美元资本的终端形态，绝不是向客户兜售 Token，而是向社会直接交付完成度极高的‘确定性认知成果’——交付一份审查完毕的并购合同、交付一段可运行的游戏代码、交付一个攻克罕见病的分子设计。"

四、 扩展律信徒的复仇：被理论家耽误的整整一代科学界

讲座最尖锐的一幕，是 Altman 对主流学术界的当面清算。

"如果回顾过去五年，很多大学实验室和知名理论家犯下的最大罪过，就是带着近乎傲慢的笃定，向整整一代年轻学生灌输‘大语言模型扩展绝不可能带来真正智能’的教条。"Altman 毫不留情，"他们写了无数篇数学论文，证明自回归必然崩溃、证明统计概率不可能产生推理。但在工程一线，我们这帮人只是默默看着对数线性的性能曲线——它依然在以极其优美的斜率稳步向上延伸。我们选择相信数据，继续把算力规模推上万卡。"

现场有学生问："你总说‘我早就告诉过你们扩展律会继续生效’，你觉得烦吗？"

Altman 笑了笑："不烦，但看着那么多聪明的年轻人被误导去研究那些注定被新一代大模型彻底抹平的旁门左道，我感到非常遗憾。在今天，押注扩展律停滞，依然是整个科技界最昂贵、最具毁灭性的赌注！"

但他同时划清了边界：纯语言模型扩展虽然在符号推理上战无不胜，但如果通往具身智能与物理世界通用机器人，就必须把多模态世界模型（World Models）与强化学习深度熔铸在一起。人类认知的尽头不是文字统计，而是实体世界的交互推演。
