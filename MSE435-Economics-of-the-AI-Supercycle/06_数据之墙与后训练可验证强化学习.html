第六讲：预训练撞上数据之墙、代码作为 AGI 底座与隐式反馈飞轮

解密后训练强化学习范式革命、Cursor 遥测闭环与“坐等下一代大模型”的战略自杀

主讲：Apoorv Agrawal | 嘉宾：Yash Patil（Applied Compute 创始人兼 CEO / 前 OpenAI 研究员）

一、 预训练的终结：全人类文本枯竭与数据之墙

在第六讲的开场，Yash Patil 带领斯坦福全班直面当前深度学习理论界最大的隐秘危机：经典预训练缩放定律（Pre-training Scaling Laws）正在急剧逼近其物理极限。据 Epoch AI 量化测算，全人类文明留存在互联网上的高质量公开纯文本总存量约为数十万亿至一百万亿 Token，以 GPT-4、Claude 3.5 和 Llama-3 为代表的前沿模型，实际上已经将公网几乎所有清洗可用的语料吞噬殆尽。

如果继续强行扩大预训练数据规模，实验室将面临两大不可逆的阻碍：

  1. 模型崩溃（Model Collapse）：当互联网上充斥着越来越多由早期大模型生成的合成文本时，用这些数据递归训练下一代模型，会使生成内容的概率分布被逐渐抹平，方差急剧缩减，最终退化为语无伦次的输出。
  2. 边际信息增益断崖式下跌：人类写下的绝大多数互联网文本充斥着重复与社交琐碎。多喂给模型一万亿 Token 的论坛闲聊，对其在高等数学证明、复杂架构设计与精密法律推演上的能力提升，几乎等于零。

这一困局宣告了过去五年“只要堆砌算力和语料就能无脑升级”的时代彻底终结。前沿大模型的核心战场，正式全面转移至模型后训练（Post-Training）与强化学习（RL）的深水区。

二、 后训练范式跃迁：可验证奖励强化学习（RLVR）与算力换数据

作为曾亲历 OpenAI 核心后训练技术攻关的科学家，Yash 揭秘了新一代推理模型突破数据墙的核心机制：以可验证奖励强化学习（RLVR）实现“以计算量兑换数据质量”。其运作逻辑彻底颠覆了传统的自监督学习：

  1. 给出目标问题（Prompt）。
  2. 模型在沙盒中并行生成数千种不同的推演路径（Rollouts）。
  3. 确定性验证器对最终结果执行严格判决（1 或 0）。
  4. 仅提取通向正确答案的高价值梯度，反向更新模型的搜索策略。

在这一架构下，模型不再被动死记硬背人类写好的标准答案，而是在极高算力的催化下，在数字沙盒中通过海量试错与自我对弈，自发摸索出长链条推理、反思回溯与多步骤规划的能力。人类没有提供任何新数据，测试期算力本身就转化成了模型智力的增量。

三、 为什么代码是通往 AGI 的确定性通用底座？

为什么全球顶尖 AI 实验室的科学家们，几乎无一例外地将精力倾注在让模型“精通写代码”上？

代码为何是最理想的强化学习训练场

如果让大模型写一篇文学散文，或给出一份宏观经济走势预测，人类专家对“写得好不好”永远存在主观争议，容易诱发强化学习中的奖励作弊（Reward Hacking）。但代码拥有数字世界最纯粹的裁判——编译器与单元测试套件。一段代码要么完全合规、通过所有边界测试（Reward = 1），要么在某一行抛出异常直接崩溃（Reward = 0）。这种无需人工介入、可大规模并行的确定性反馈，正是强化学习算法最理想的养料。

更重要的是，代码是连接现实世界一切软件资产的通用接口：银行结算系统、医院病历、卫星测控网络与企业数据库，底层都可以通过代码脚本与 API 调用。一旦模型精通代码，它就不再只是聊天窗口里的清谈客，而是拥有了直接操纵数字化实体经济的手和神经系统。

这也解释了为什么在非代码领域（如制作商业 PPT、法律合规审核、创意设计）AI 的进化相对迟缓——这些领域缺乏一个像编译器一样廉价、客观、坚不可摧的评估体系（Evals）。谁能为特定垂直行业构建出防作弊的自动评估沙盒，谁就能复制出代码维度的强化学习飞轮。

四、 案例解剖：Cursor 与 Composer 的隐式遥测飞轮

许多人以为 AI 编程工具 Cursor 仅仅是给 VS Code 套了一层 Claude 的 API 接口。Yash 在课堂上指出，Cursor 自研模型 Composer 每天在后台捕获全球数十万工程师数以千万计的细微编辑动作，这种生产环境遥测数据的信息纯度远超任何公开代码库，由此构筑了一套“线上隐式反馈闭环”：

  • 毫秒级意图遥测：当系统为工程师补全一段逻辑时，用户是在 0.2 秒内按下 Tab 采纳，还是 3 秒后按下 Cmd+Z 撤回？是否在采纳后又手动修改了变量名？终端是否随后抛出了构建错误？
  • 隐式奖励提炼：Cursor 将这些无意识产生的开发者交互信号，自动清洗转化为偏好优化数据对（Preference Pairs）。
  • 线上持续后训练：利用这一源源不断的高纯度反馈流，Cursor 在开源模型底座之上持续进行 DPO（直接偏好优化）与轻量策略更新。通用大模型实验室即使算力再庞大，只要没有真实的开发者 IDE 入口，就无法触碰这一数据飞轮。

五、 终局警示：“坐等下一代模型”的企业投机谬论

在课程的最后问答环节，有学生提出：“很多企业高管私下认为，现在花钱清洗私有数据、训练自己的小模型是浪费钱；只要耐心等待一两年，等 OpenAI 发布下一代基座模型，通用智力的暴涨就会自然解决企业的一切问题。这种‘躺平等待策略’在商业上是否最具资本效率？”

等待更强模型不是谨慎，而是战略懒惰

未来的基础大模型在通用智力上会越来越强，但它对某家跨国物流公司内部十几年积累的专有仓储数据流、对特定工厂设备的异常容错规则依然一无所知——通用模型面向全人类最大公约数训练，不会为特定业务做专门适配。

真正的差距在于飞轮复利的时间差：今天就开始搭建私有数据后训练流水线、构建垂直领域评估体系的企业，正在积累独一无二的领域微调经验。当新一代基座模型发布时，这些企业只需几周就能把新底座换入已有的飞轮，业务性能随即再次拉开身位；而选择等待的企业，即便拿到最新模型，也依然不知道该如何让它跑通自己业务里的第一个单元测试。
