第六讲：预训练撞上数据之墙、代码作为 AGI 底座与隐式反馈飞轮

解密后训练强化学习范式革命、Cursor 遥测闭环与“坐等下一代大模型”的战略自杀

主讲：Apoorv Agrawal | 嘉宾：Yash Patil（Applied Compute 创始人兼 CEO / 前 OpenAI 研究员）
“整个 AI 行业正在发生一场秘而不宣的重心大迁移：依靠在全网无脑爬取人类文本进行预训练的时代已经撞上了坚硬的物理之墙。今天最顶级的智力提升，不再来自于‘读了多少书’，而来自于‘在严密的仿真沙盒中，通过数百万次试错与编译验证，自己学会了如何推理’。代码不是程序员的专属工具，代码是人类迄今创造的最完美、最不容欺诈的通用真理编译器。”
, Yash Patil, 前 OpenAI 后训练科学家

一、 预训练的终结：全人类文本枯竭与“数据之墙”

在第六讲的开场，Yash Patil 带领斯坦福全班直面当前深度学习理论界最大的隐秘危机：**经典预训练缩放定律（Pre-training Scaling Laws）正在急剧逼近其物理极限**。 据 Epoch AI 量化测算，全人类文明留存在互联网上的高质量公开纯文本总存量约为 数十万亿至一百万亿 Token。以 GPT-4、Claude 3.5 和 Llama-3 为代表的前沿模型，实际上已经将公网几乎所有清洗可用的语料全部吞噬殆尽。

如果继续强行扩大预训练数据规模，实验室将面临两大不可逆的致命阻碍：

  1. 合成数据自噬导致的“模型崩溃（Model Collapse）”：当互联网上充斥着越来越多由早期大模型生成的合成垃圾文本时，如果用这些包含统计微小偏差的数据去递归训练下一代模型，模型的尾部概率分布会被严重抹平，导致生成内容方差急剧缩减，最终退化为语无伦次的语言混乱。
  2. 边际信息增益断崖式下跌：人类写下的绝大多数互联网文本充斥着废话、重复与社交琐碎。多喂给模型一万亿 Token 的 Reddit 帖子或论坛闲聊，对模型在高等数学证明、复杂架构设计与精密法律推演上的能力提升，几乎等于零。

这一困局宣告了过去五年“只要堆砌算力和语料就能无脑升级”的暴力美学彻底终结。前沿大模型的核心战场，正式全面转移至**模型后训练（Post-Training）与强化学习（RL）**的深水区。

二、 后训练范式跃迁：可验证奖励强化学习（RLVR）与算力换数据

作为曾亲历 OpenAI 核心后训练技术攻关的科学家，Yash 揭秘了新一代推理模型如何突破数据墙的核心机制：以可验证奖励强化学习（Reinforcement Learning with Verifiable Rewards, RLVR）实现“以计算量兑换数据质量”。

其底层运作逻辑彻底颠覆了传统的自监督学习： RLVR 闭环运作机制：
• 1. 给出目标问题（Prompt）。
• 2. 模型在沙盒中并行生成数千种完全不同的推演路径（Rollouts）。
• 3. 确定性验证器对最终结果执行严格判决（1 或 0）。
• 4. 仅提取通向正确答案的高价值梯度，反向更新模型内部的搜索策略。

在这一架构下，模型不再被动死记硬背人类写好的现成标准答案，而是在极高算力的催化下，在数字沙盒中通过海量试错与自我对弈，自发摸索出长链条推理、反思回溯（Backtracking）与多步骤规划的高维逻辑。人类没有提供任何新数据，但万卡集群的测试期算力直接转化成了模型高阶智力的内生增量。

三、 为什么代码是通往 AGI 的唯一确定性通用底座？

为什么全球顶尖 AI 实验室的顶流科学家们，无一例外地将全部精力倾注在让模型“精通写代码”上？代码难道仅仅是程序员的专业技能吗？

犀利穿透：代码作为宇宙真理编译器的三大神圣特权
Yash 给出了全场最具哲学高度的技术剖析：

1. 绝对客观的布尔值真理（Boolean Ground Truth）： 如果你让大模型写一篇文学散文，或者给出一份宏观经济走势预测，人类专家对于“写得好不好”永远存在主观争议与评判偏差，极易诱发强化学习中的“奖励作弊（Reward Hacking）”。 但代码拥有人类数字文明中最纯粹的裁判员, , 编译器与单元测试套件（Compiler & Test Suite）。一段代码，要么在语法上完全合规、成功通过所有极限边界测试并返回预期哈希值（Reward = 1），要么在第 42 行抛出空指针异常直接崩溃（Reward = 0）。这种严密、无需人工介入、可自动化大规模并行的确定性反馈，是强化学习算法最梦寐以求的黄金滋养土壤。

2. 连接现实世界一切软件资产的终极 API： 在这个世界上，所有的银行结算系统、所有的医院病历档案、所有的卫星测控网络和所有的企业数据库，在底层全都可以通过代码脚本和 API 接口进行调用。当一个模型彻底精通了代码，它就不再是一个只能在聊天窗口里动嘴皮子的清谈客，而是拥有了直接操纵整个人类数字化实体经济的强壮双手与神经系统。

这也解释了为什么在非代码领域（如制作商业 PPT、法律合规审核、创意设计）AI 的进化相对迟缓。 因为在这些领域中，**缺乏一个像编译器一样廉价、客观且坚不可摧的“评估体系（Evals）”**。谁能为特定的垂直行业构建出防作弊的高阶自动评估沙盒，谁就能在该领域复制出代码维度的强化学习飞轮。

四、 案例解剖：Cursor 与 Composer 的隐式遥测（Telemetry）飞轮

许多人以为 AI 编程工具 Cursor 仅仅是给 VS Code 套了一个 Claude 的 API 接口。Yash 在课堂上彻底推翻了这一浅薄的认知，深入剖析了 Cursor 自研模型 Composer 构筑的致命防御工事： 据开发者社区估算，Cursor 每天在后台捕获全球数十万顶尖工程师数以千万计的细微编辑动作，这种具备极高密度的生产环境遥测数据，其信息纯度远超任何公开开源代码库。

Cursor 建立了一套令通用大模型实验室望尘莫及的“线上隐式反馈闭环（Online Implicit Feedback Loop）”：

  • 毫秒级的意图遥测：当系统为工程师补全了一段逻辑时，用户是在 0.2 秒内按下了 Tab 键采纳？还是在 3 秒后愤怒地按下了 Cmd+Z 撤回修改？用户是否在采纳后，立刻在第 15 行手动修改了一个变量名？终端在 5 秒后是否抛出了构建错误？
  • 从人机互动提炼隐式奖励（Implicit Rewards）：Cursor 将这些全天候无意识产生的人类开发者交互信号，自动化清洗转化为精准的偏好优化数据对（Preference Pairs）。
  • 线上在线学习与针对性后训练：利用这一源源不断的高纯度反馈流，Cursor 在开源模型底座之上持续进行 DPO（直接偏好优化）与轻量化策略更新。通用大模型实验室即使拥有再庞大的算力，只要他们没有掌握真实的开发者 IDE 入口，就永远无法触碰到这一黄金数据飞轮。

五、 终局警示：痛击“坐等 GPT-17 拯救世界”的企业投机谬论

在课程的最后问答环节，有学生提出：“很多企业高管私下认为，现在花费数百万美元去清洗私有数据、训练自己的小模型完全是浪费钱；只要耐心等待一两年，等 OpenAI 发布 GPT-5、GPT-6 甚至 GPT-17，通用基座模型的智力暴涨就会自然而然解决企业的一切问题。这种‘躺平等待策略’是否在商业上最具资本效率？”

Yash 的绝杀反驳：战略懒惰者的必然消亡
“这是我在硅谷见过的最愚蠢、最具破坏性的企业战略懒惰。”

第一，通用智力的边际递减与企业深水区的隔阂： 未来的基础大模型在通用智力上确实会越来越强，但它对你这家特定跨国物流公司内部 15 年来盘根错节的专有仓储数据流、对你特定复杂工厂设备的异常容错规则，依然一无所知。通用模型是面向全人类最大公约数训练的，它绝不会为了你的特定业务做专门适配。

第二，飞轮复利的时空代差： 那些在今天就开始沉下心搭建私有数据后训练流水线、构建严格垂直领域 Evals 评估体系的企业，正在积累独一无二的“领域微调经验与自动化闭环能力”。 当未来的 GPT-5 或新一代开源模型发布时，这家已经拥有成熟后训练基础设施的企业，只需要花两周时间将新的通用底座替换进已有的飞轮中，其专用业务性能就会瞬间再次拉开同行数个身位！ 而那些选择躺平等待的企业，即使拿到了最新模型，也依然不知道该如何让它在自己混乱的业务流中跑通第一个单元测试。在科技超级周期中，等待不是谨慎，而是变相的战略自杀。
