第十一讲：分词多语言性与可解释性

分词这个看似技术细节的选择，会系统性地让某些语言的使用者多付钱、少得到好结果

客座主讲：Julie Kallini（分词与多语言性）、Been Kim（可解释性）
对应真实课程材料：Lecture 14（Tokenization and Multilinguality）、Lecture 15（Interpretability）

一、 分词器和模型训练数据不一致，会留下"故障 token"

第一讲提到的字节对编码（BPE），训练分词器所用的语料，和后续训练语言模型本身所用的语料，实际操作中未必完全一致。如果某个 token 在分词器训练语料里出现得足够频繁、被收入了词表，但在语言模型正式训练时用的语料里却极少出现甚至完全没出现，这个 token 对应的向量表示就几乎没有被真正训练过，停留在接近随机初始化的状态，模型遇到这个 token 时的行为会变得不可预测，这类 token 被称为故障 token（glitch token）。

一个真实且广为人知的例子是 SolidGoldMagikarp：这是一个在某个网络社区里被过度使用、因而意外被收进 GPT 系列早期分词器词表的用户名。当有人要求 GPT-3 复述或解释这个 token 时，模型会给出前后不连贯的回答，比如无端联想到"distribute"这个词，或者干脆拒绝、无法正确复述这个词本身。2024 年 Land 和 Bartolo 的研究开发出自动检测这类故障 token 的方法，发现类似问题广泛存在于 GPT-2、LLaMA、OLMo、Qwen 等多个不同厂商的模型里，说明这不是某一家的偶然失误，而是"分词器训练数据和模型训练数据不一致"这个流程性问题的普遍后果，代价不只是浪费掉几个词表位置，还可能被利用为一种对抗攻击的入口。

二、 多语言为什么重要，以及分词器如何悄悄制造不公平

世界上有超过 7000 种有文字记录的语言，说英语的人口约占全球两成，但把英语当作母语的人口比例大约只有 5%。然而 Common Crawl 这类大规模网页语料库里，英语内容占比高达 40% 到 45%，大量语言（比如塔加洛语、阿姆哈拉语、约鲁巴语）在这类语料里的占比不到万分之一，这类数字资源稀缺的语言被称为低资源语言，与之相对的是英语这类数字资源充裕的高资源语言。

不公平从分词这一步就已经开始，甚至早于模型训练本身。同一句话，用同一个分词器（比如 ChatGPT 的分词器）处理，英语可能只需要 21 个 token，法语需要 27 个，索马里语需要 30 个，泰语则需要 36 个，2023 年 Petrov 等人的研究发现，同等语义内容在不同语言之间的分词长度差异最高可达 15 倍。这个差异不只是效率问题：2023 年 Ahia 等人系统分析了 OpenAI API 在 22 种语言上的真实计费情况，发现很多语言的使用者，为表达同样多的意思，需要消耗更多 token，也就是要付更多的钱，同时因为分词效率更低，模型对这些语言的理解和生成效果通常也更差，而这些语言的使用者，往往还来自本就更难负担这类 API 服务的地区。这里有一个专门的度量指标叫子词生育率（subword fertility），也就是平均每个词会被切成多少个子词 token，研究发现子词生育率和下游任务表现之间存在明显的负相关，生育率越高，说明这门语言被切得越碎，模型效果往往越差。

多语言模型的训练方式，架构上和单语言模型完全一样，区别只在于分词器和训练语料本身覆盖多种语言，比如 2020 年发布的 XLM-R，用跨越 100 种语言、2.5TB 规模的 Common Crawl 数据做掩码语言建模训练。这类模型展现出一种很有价值的能力，跨语言迁移（cross-lingual transfer）：只用英语的标注数据微调一个分类任务，模型不需要看过任何其他语言的标注样本，就能直接在其他预训练时见过的语言上完成同样的分类任务，因为不同语言的文本在共享的表示空间里，被映射到了相近的区域。研究还发现，词表之间的重叠程度越高，这种跨语言迁移的效果通常越好，即便是"看起来相同但含义不同"的这类偶然重叠 token，也能在一定程度上帮助建立有用的跨语言表示。

但这种迁移能力并非没有代价，这一讲称之为"多语言的诅咒"：在模型参数容量固定的前提下，训练覆盖的语言数量增加到一定程度之后，每种语言能分摊到的有效建模能力反而开始下降。一项在跨语言自然语言推理基准 XNLI 上的实验显示，同一个 XLM-R 架构，覆盖 7 种语言时准确率是 71.8%，覆盖到 100 种语言时准确率降到 67.7%，高资源语言（比如英语、法语）随着语言数量增加，性能持续下滑，而低资源语言虽然一开始能从跨语言迁移中获益，但语言数量继续增加之后，最终也会遭遇同样的性能下降。

三、 可解释性：模型给出的"解释"，可信吗

这一讲后半部分的客座主讲人 Been Kim，长期在 Google DeepMind 从事可解释性研究，她的研究方向对这个领域一个常见但值得警惕的思路提出了持续的质疑：很多所谓的"模型解释"，本质上是在模型给出答案之后，另外生成一段听起来合理的文字来解释这个答案，这种事后生成的解释文字，不一定真实反映了模型内部实际发生的计算过程，两者之间可能完全脱节，一段读起来很有说服力的解释，并不能保证它就是模型真正依据的理由。

Been Kim 更早期的代表性工作之一是 2018 年提出的概念激活向量测试（Testing with Concept Activation Vectors, TCAV）：与其停留在"模型关注了图片里的哪些像素"这类底层特征归因，不如直接检验一个人类能理解的高层概念（比如"条纹"这个概念），是否真的对模型判断某个类别（比如"斑马"）产生了可以量化的影响，具体做法是在模型的内部表示空间里，找到一个能代表这个概念的方向，再测量沿这个方向的扰动，对模型最终输出的影响有多大。这类方法试图把可解释性研究，从"这张图哪里亮"这种不容易验证的直觉展示，推进到更接近科学实验、结论可以被检验和证伪的方向。

这一讲想传达的态度，和上一讲评估方法论的态度是一致的：不管是一个基准测试的高分，还是一段模型给出的自我解释，都不应该仅凭它"看起来令人信服"就被直接采信，都需要独立于模型本身的、可以被检验的证据来支撑。
