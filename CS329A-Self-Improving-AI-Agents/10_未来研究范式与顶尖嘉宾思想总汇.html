第十讲：未来研究前沿与特邀顶尖嘉宾思想全集

DeepMind 算力智囊、IMO 奥赛金牌突破、物理具身机器人与分布式内存架构闭门论道

特邀先锋：Denny Zhou · Thang Luong · Melvin Johnson · Junchen Jiang · Misha Laskin · Danny Driess
学术主持：Aakanksha Chowdhery & Azalia Mirhoseini · 斯坦福 Skilling 礼堂闭门研讨全景录

一、 顶尖特邀嘉宾研讨谱系

除了九大核心技术专题外，两位主讲导师邀请了六位身处人工智能最深水区的领军人物走上斯坦福 Skilling Auditorium 的讲台。他们的分享脱离了面向公众的技术公关话术，用严苛的工程实测和尚未公开的前沿问题，勾勒出了未来十年自演进智能的技术蓝图。

二、 Denny Zhou（Google DeepMind）：思维链的计算本质

Denny Zhou 是 Google DeepMind 推理研究团队（Reasoning Team）的总负责人，也是思维链（Chain of Thought, CoT）、Least-to-Most Prompting 与 Self-Consistency 机制的核心开创者。在题为《LLM Reasoning》的讲座中，他澄清了一个常见的误解：思维链不是模型在“自言自语”，而是 Transformer 在时间轴上动态展开出的一套额外计算层。

一个固定 L 层的 Transformer，单次前向传播只能表达电路复杂性理论中 TC0 类别的计算：如果不展开中间 Token，模型甚至无法在数学上判定一个括号序列是否合法匹配。而模型每吐出一个中间 Token，就相当于在这套固定网络上临时多插了一层计算：输出 500 个词的思考链，等于把网络从 32 层临时拉长到了 532 层。这正是“多打草稿”能显著提升复杂推理能力的原因。

Denny 认为，未来的自演进模型应当摆脱自然语言对思维过程的束缚，让中间推理由不可读但信息密度更高的潜空间隐式 Token（Latent Tokens）构成，从而把推理吞吐量提升两个数量级。

三、 Thang Luong（Google DeepMind）：AlphaProof 与奥赛金牌

Thang Luong 是 Google DeepMind 首席科学家兼研究总监，领衔的 AlphaGeometry 2 与 AlphaProof 团队在 2024 年国际数学奥林匹克竞赛（IMO）上首次达到银牌水平，2025 年依托 Gemini 神经符号架构拿下了人类历史上首枚 IMO 金牌标准的成绩。

他指出，自然语言数学推导充满语义多义性和难以自我发现的细微谬误。一道 IMO 级别的题目，只要第 14 步引理中有一个隐式条件未被验证，后面写得再华丽也毫无意义。AlphaProof 的解法是让两套系统分工：Gemini 扮演“直觉生成器”，在几何与代数空间中提出可能成立的辅助线与变形猜想；每一步都被翻译成形式化数学语言 Lean 4 的代码，由 Lean 内核充当“严密法官”，编译报错即判定为假，通过类型检查即为真理，再用自博弈强化学习持续迭代。

Thang 的结论是：当大模型戒断对自然语言文本的依赖，转而拥抱带有形式化编译器的数学语言时，超越人类的数学推理能力就不再是遥不可及的设想。

四、 Melvin Johnson（Google DeepMind）：从 Chatbot 到 Agent 的后训练转向

Melvin Johnson 是 Google DeepMind 的杰出科学家，过去十年主导了 Google 机器翻译、多语言模型与 Gemini 后训练架构的演进。他提出的问题是：为什么用微调 Chatbot 的方法去微调 Agent 必然失败？

传统 RLHF 优化的是人类单次交互的愉悦感，模型被教导要立刻回复、语气礼貌笃定，不能沉默超过几秒。但一个优秀的 Agent 需要的品格恰恰相反：面对复杂的数据库迁移任务，它应该能心平气和地尝试多种方案，容忍连续几十次工具报错并默默自纠错，而不是第一时间抛出一段未经检验的漂亮空话。Melvin 认为，后训练必须从偏好对齐全面转向执行对齐，让奖励模型的唯一标尺变成任务的实际交付结果。

五、 Junchen Jiang（UChicago / LMCache）：长上下文的内存墙

Junchen Jiang 是芝加哥大学副教授、推理缓存系统 LMCache 联合创始人。在《Augmenting Agents with Memory》讲座中，他把焦点从算法理论拉回到底层显存的物理现实：一个 70B 参数模型在 100 万 Token 上下文下，仅存放 KV Cache 所需的 GPU 显存就高达数百吉字节，足以占满一整台 8 卡 H100 服务器的 HBM，首字延迟因此飙升至数十秒，推理成本暴涨上百倍。

他的解法是像操作系统管理虚拟内存一样，为 Agent 的长期记忆做分层存储：活跃上下文留在昂贵的 GPU HBM 中，次活跃的历史背景压缩后卸载到主机 CPU DRAM 或高速 NVMe SSD，多个并发 Agent 之间共享只读知识的 KV Cache。没有这样的分布式缓存系统，长记忆 Agent 只能停留在纸面上。

六、 Misha Laskin（Reflection AI）：异步强化学习的落地教训

Misha Laskin 是 Reflection AI 联合创始人兼 CEO，曾任 DeepMind 强化学习科学家。他分享了构建大规模生产级 Agent 时遇到的两个真实陷阱：

  • 同步编排的瘫痪：多数开源 Agent 框架采用同步阻塞循环，只要一个外部 API 出现几秒延迟，整个智能体蜂群的吞吐量就会归零。Reflection AI 转向了事件驱动的异步 Actor-Critic 架构。
  • 生产环境的数据漂移：在沙盒中训练完美的 Agent，一进生产环境面对真实用户的脏数据就会性能折半。唯一有效的解法是持续在线强化学习，让 Agent 每天从生产环境的失败日志中更新自己的 LoRA 适配层。

七、 Danny Driess（Physical Intelligence）：具身智能与 π0 流模型

Danny Driess 是具身智能公司 Physical Intelligence 的创始团队成员，也是 Google 具身模型 PaLM-E 的第一作者。在压轴讲座《Multimodal AI Agents in Robotics》中，他带来了这门课最大的一次视角切换：从数字比特走向物理原子。语言模型犯错，无非是抛出一个异常或重新生成一次字符串；但机械臂把一个玻璃杯摔在地上，这个错误永远无法撤销。

传统机器人策略把连续动作切成离散 Token，面对折叠衣物、精确插拔这类精细操作时容易产生动作抖动。Physical Intelligence 的 π0（Pi-Zero）把视觉语言基座与流匹配（Flow Matching）连续动作头结合起来：以 1-3 Hz 的频率用视觉语言模型做宏观语义推理（找到目标、识别材质、规划抓取角度），再以 50 Hz 的高频用流匹配头直接输出多自由度机械关节的连续扭矩与速度。

Danny 的结论是：物理现实是自演进 AI 最残酷的训练场，因为在重力和热力学定律面前，任何统计偏见都无法蒙混过关，只有在物理世界中真正站得住脚的智能体，才配被称为 AGI。
