第六讲：训练期算力自举：STaR、GRPO 与 DAPO 熵防御

扔掉 Critic 价值网络的减法、组相对优势优化与非对称梯度裁剪

核心文献：STaR (Zelikman et al.) · DeepSeekMath (Shao et al.) · DAPO System (2025)
主讲教授：Aakanksha Chowdhery & Azalia Mirhoseini · 训练期强化学习缩放（Train-Time Scaling）

一、 训练期自举：把搜索沉淀回权重

在前几讲中，我们见证了测试期计算（Test-time Compute）在单题解题上的威力。然而，若每次面对用户提问都要在后台展开上万次蒙特卡洛采样或树搜索，推理成本与响应延迟会拖垮绝大多数实际业务。自演进系统的核心问题因此变成：如何让模型在推理时靠搜索算力探索出的路径，反过来沉淀为模型参数本身的直觉？

由 Eric Zelikman 等人提出的 STaR（Self-Taught Reasoner）开创了这一思路，用推理自举推理：当模型无法独立做出正确推导时，环境先把正确答案作为提示，引导模型反向推出完整逻辑链条，再把这条自洽路径加入微调集，从而突破冷启动障碍。

二、 GRPO：抛弃 Critic 价值网络

过去数年，近端策略优化（PPO）几乎是强化学习对齐的唯一范式，但在千亿参数模型上，PPO 的开销令人窒息：它需要在训练策略网络（Actor）的同时，额外加载一个同等体量的价值网络（Critic）Vϕ(s) 来估计每个 Token 的基线价值，显存需求与梯度同步通信量因此翻倍；而在数千 Token 的长思维链中，Critic 又很难精准预测每个中间 Token 的价值期望，方差剧烈震荡，策略梯度频繁发散。

Shao 等人（2024）在《DeepSeekMath》中提出的 GRPO（Group Relative Policy Optimization），用一次纯粹的减法扔掉了 Critic：对同一道题目，让模型一次性采样一组候选答案，用组内奖励的相对均值作为基线，不再需要额外的价值网络。 

GRPO Algorithm Mechanism:
For each prompt q:
  1. Sample a group of G candidate outputs: {o_1, o_2, ..., o_G} ~ \pi_{old}(· | q)
  2. Evaluate deterministic ground-truth rewards: {R_1, R_2, ..., R_G}
  3. Compute Group Relative Advantage for each candidate i:
     A_i = ( R_i - mean({R}) ) / ( std({R}) + \epsilon )
  4. Optimize Actor Policy directly with PPO-style clipping & KL penalty

GRPO 的优化目标为：

$$\mathcal{J}(\theta) = \mathbb{E}\left[ \frac{1}{G}\sum_{i=1}^G \min\left( r_i(\theta) A_i, \text{clip}(r_i(\theta), 1\pm\epsilon) A_i \right) - \beta D_{\text{KL}}(\pi_\theta || \pi_{\text{ref}}) \right]$$

其中比率 ri(θ) = πθ(oi|q) / πold(oi|q)，基线完全由同组样本的相对均值给出。这一设计为万卡集群省下数百吉字节显存，训练吞吐量提升超过一倍。

三、 熵崩溃：模型如何失去探索能力

当各前沿团队把 GRPO 放大到更大规模时，都撞上了同一堵墙，策略熵崩溃（Entropy Collapse）。训练进行到中后期，模型输出的香农熵会出现断崖式坍缩：一旦某条固定模板恰好在某次答题中获得了微弱正奖励，对称裁剪就会把这条模板里每个 Token 的概率迅速推向 0.9999。

标准 PPO/GRPO 的梯度裁剪范围是对称的（例如 ε = 0.2，重要性权重被限制在 [0.8, 1.2]），这种对称性在抑制劣解上过于激进。一旦策略熵趋近于零，模型就丧失了在概率空间中探索新解题路径的能力，此后无论输入什么题目，都只会机械套用少数几种固化模板，面对长尾新题时表现迅速崩溃。

四、 DAPO 的解药：非对称裁剪

2025 年开源的大规模强化学习系统 DAPO（An Open-Source LLM Reinforcement Learning System at Scale）为这一问题给出了一个精妙的方案：非对称梯度裁剪（Clip-Higher）。传统对称裁剪假设鼓励（Advantage > 0）与抑制（Advantage < 0）应有相同的边界幅度 ±0.2，DAPO 打破了这一假设：

$$\text{clip}\left( r_i(\theta), 1 - \epsilon_{\text{low}}, 1 + \epsilon_{\text{high}} \right)$$

下限仍锚定在 εlow = 0.2，上限却放宽至 εhigh = 0.28 ~ 0.35。真正有创造性的推理步骤，在模型早期的先验里往往是低概率事件；放宽上界，让那些获得高奖励的稀有路径在单次反向传播中获得更大的概率提升空间，才能冲破主流平庸路径的阻碍。

实测数据显示，引入 Clip-Higher 后，策略网络的探索熵在整个训练周期内维持在健康区间，模型自发演化出长达数万 Token 的自主回溯与验算能力，打破了困扰学术界已久的强化学习早衰问题。
