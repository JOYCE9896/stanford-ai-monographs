第六讲：训练期算力自举：STaR 推理飞轮、DeepSeekMath GRPO 与 DAPO 熵防御

扔掉 Critic 价值网络的优雅减法、组相对优势优化与非对称梯度裁剪的物理机制

核心文献：STaR (Zelikman et al.) · DeepSeekMath (Shao et al.) · DAPO System (2025)
主讲教授：Aakanksha Chowdhery & Azalia Mirhoseini · 深入解构训练期强化学习缩放（Train-Time Scaling）
“测试期的搜索探索无论多么绚丽，如果不能被系统性地蒸馏并固化回神经网络的前向权重中，模型就永远只是一台用昂贵电费堆砌起来的高延时临时计算机。真正的自演进，必须完成‘搜索外循环 → 权重内循环’的自举对弈闭环。”
, Aakanksha Chowdhery, Stanford CS329A 讲堂实录

一、 训练期自举：如何拔着自己的头发离开地球？

在前几讲中，我们见证了测试期计算（Test-time Compute）在单题解题上的惊人威力。然而，若每一次面对用户提问都需要在后台展开 10,000 次蒙特卡洛采样或多步树搜索，其商业推理成本（COGS）与响应延迟将彻底杀死绝大多数实际业务。

因此，自演进 AI 系统的核心圣杯变成了：如何让模型在推理时消耗大量搜索算力探索出的“真理路径”，反哺并沉淀为模型参数本身所具备的“直觉本能”？

由 Eric Zelikman 等人提出的 STaR（Self-Taught Reasoner） 开创了这一先河。其核心思想是“用推理自举推理”： STaR 引入了极其精妙的合理化提示（Rationalization）：当模型无法独立做出正确推导时，环境先将最终正确答案作为提示提供给模型，引导模型“反向倒推”出完整的逻辑链条，随后将这条自洽路径加入微调集，从而突破冷启动障碍。

二、 GRPO：抛弃 Critic 价值网络的数学革命

在过去数年中，近端策略优化（PPO）是强化学习对齐的唯一黄金法则。然而，在以千亿参数大模型为基座的训练中，PPO 的系统开销沉重到令人窒息：

【通俗白话拆解】什么是 Actor-Critic？DeepSeek 的 GRPO 到底神在哪里？

如果你听过强化学习，通常会被里面的“策略网络（Actor）”和“价值网络（Critic）”搞得云里雾里：

  • 传统的 PPO（配随身私教）：大模型自己是做题学生（Actor）。为了让它知道每一步做对没有，PPO 必须在显存里额外塞进一个体量一模一样的私教模型（Critic），时时刻刻盯着学生打分。这直接导致 GPU 显存消耗翻倍，而且私教自己经常看花眼打错分。
  • DeepSeek 的 GRPO（组内同学互评）：DeepSeek 做出了一次天才级的减法, , 把私教直接辞退！同一个题目，让模型一口气写出 8 个不同的解答（组成一个 8 人学习小组）。计算这 8 个解答的平均分，凡是比组内平均分高的解答就狠狠奖励，比平均分低的就惩罚。根本不需要额外的私教模型，显存直接省出一半，训练吞吐量翻倍！
  • 显存翻倍与通信拥堵：PPO 必须在训练 Actor 策略网络的同时，额外加载一个同等体量的 Critic 价值网络 Vϕ(s)，用于估计每个 Token 的基线价值。这直接将集群的显存需求与梯度同步通信量翻了一倍。
  • Critic 在长文本上的拟合崩溃：在成千上万个 Token 的长思维链中，Critic 网络极其难以精准预测每个中间 Token 的连续价值期望，导致方差剧烈震荡，策略梯度频繁发散。

DeepSeekMath 的破局之刃：组相对策略优化（GRPO）

由 Shao 等人（2024）在《DeepSeekMath》中提出的 GRPO（Group Relative Policy Optimization），以极其纯粹的数学减法彻底扔掉了 Critic 网络！ 

GRPO Algorithm Mechanism:
For each prompt q:
  1. Sample a group of G candidate outputs: {o_1, o_2, ..., o_G} ~ \pi_{old}(· | q)
  2. Evaluate deterministic ground-truth rewards: {R_1, R_2, ..., R_G}
  3. Compute Group Relative Advantage for each candidate i:
     A_i = ( R_i - mean({R}) ) / ( std({R}) + \epsilon )
  4. Optimize Actor Policy directly with PPO-style clipping & KL penalty

GRPO 的目标函数写为： GRPO 优化目标：
$$\mathcal{J}(\theta) = \mathbb{E}\left[ \frac{1}{G}\sum_{i=1}^G \min\left( r_i(\theta) A_i, \text{clip}(r_i(\theta), 1\pm\epsilon) A_i \right) - \beta D_{\text{KL}}(\pi_\theta || \pi_{\text{ref}}) \right]$$
其中比率 ri(θ) = πθ(oi|q) / πold(oi|q)。完全由同组样本的相对均值充当基线，无需任何额外的参数网络！

这一优雅设计不仅为万卡集群省下了数百吉字节的高昂显存，更使得强化学习训练的吞吐量飙升了整整一倍以上。

三、 致命的病理学：强化学习中的“熵崩溃（Entropy Collapse）”

然而，当各前沿团队兴高采烈地将 GRPO 规模化放大到更大计算量时，所有人都迎头撞上了一堵无形的物理墙, , 策略熵崩溃（Entropy Collapse）。

病理诊断：为什么模型会突然失去思考灵性，沦为僵死的复读机？
在强化学习训练到特定中后期（通常在数千步迭代后），研究者观察到模型的输出香农熵（Policy Entropy）出现断崖式坍缩。

通俗大白话比喻： “熵”代表可能性的多样性。一个学生如果在某次模考中偶然靠“选择题全部选 C”碰巧得了及格分，在缺乏正确引导下，他就会坚信“选 C 是保底神技”。从此外界无论怎么出题，他脑子里除了 C 再也想不到别的选项, , 他的思维多样性彻底死绝了，这就是“熵崩溃”。

底层致病机理分析： 在标准的 PPO/GRPO 中，梯度的裁剪范围是对称的（例如 ε = 0.2，即将重要性权重严格限制在 [0.8, 1.2]）。 当模型偶然在一道代数题中通过某条特定格式的模板（比如在开头写死“让我们分三步分析…”）获得了微弱正奖励后，由于对称裁剪在抑制劣解方面极度激进，模型会迅速将该模板中每一个固定 Token 的概率推向 0.9999。

一旦策略熵趋近于零，策略网络就彻底丧失了在概率空间中探索全新解题路径的能力！ 此后无论给它输入什么题目，它都会机械化地套用极少数几种固化模板，面对稍有变动的长尾新题瞬间暴毙。这种灾难性的探索能力灭绝，被称为 RL 强化学习的“脑死亡”。

四、 DAPO 系统的解药：非对称“Clip-Higher”与探索力庇护

在 2025 年开源的分布式大规模强化学习系统 DAPO（An Open-Source LLM Reinforcement Learning System at Scale） 中，研究者为这一顽疾开出了一剂极其精妙的解药：非对称梯度裁剪（Clip-Higher）。

核心创新：以非对称容忍度庇护低概率探索芽苗
传统对称裁剪假设：鼓励（Advantage > 0）与抑制（Advantage < 0）应该拥有相同的边界幅度 ±0.2。

DAPO 颠覆了这一平衡，采用了非对称截断空间：

$$\text{clip}\left( r_i(\theta), 1 - \epsilon_{\text{low}}, 1 + \epsilon_{\text{high}} \right)$$ 其中将下限严格锚定在 εlow = 0.2，而将上限大幅放宽至 εhigh = 0.28 ~ 0.35！

数学直觉背后的惊天逆转： 那些真正蕴含着创造性与突破性思维的创新推理步骤，在模型早期的先验中往往属于极低概率事件（Low-Probability Tokens）。 放宽上界（Clip-Higher），允许那些获得了极高客观奖励（如攻克了此前从未解开的难题）的创新罕见路径，在单次反向传播中获得更大跨度的概率抬升空间，从而冲破主流高概率平庸路径的重重阻碍！

实验战果： DAPO 实测数据显示，引入 Clip-Higher 后，策略网络的探索熵在整个万步训练周期内始终维持在健康的平稳区间，模型自发演化出了长达数万 Token 的“自主回溯、验算重推与顿悟时刻（Aha Moment）”，成功打破了困扰学术界已久的强化学习早衰魔咒。
