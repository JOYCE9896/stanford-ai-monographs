第九讲：Agentic 评测科学：长周期任务度量与 GDPVal 真实经济价值

告别 MMLU 刷榜数字游戏，直面长程任务的成功率断崖与裁判模型的自评偏差

核心文献：Measuring AI Ability to Complete Long Tasks (2025) · GDPVal (2025) · DeepScholar-Bench
主讲教授：Aakanksha Chowdhery & Azalia Mirhoseini · 智能体评测科学（Agent Evaluation & Benchmarks）

一、 为什么传统 Benchmark 全面失效

主流大模型实验室长期靠公布 MMLU、GSM8K、HumanEval 的排行榜得分证明自己技术领跑，但工业界的真实体感已经与之撕裂：一个基准测试得分超过 90% 的模型，被丢进一个包含 5 万行历史遗留代码的企业代码库去修复一个异步死锁 Bug 时，表现往往接近于零。据斯坦福基准监测数据，MMLU 与 GSM8K 的测试集在各大实验室的预训练数据中已被严重污染，模型很多时候不是在推理，而是在背题。

主要 Benchmark 一览

  • MMLU：57 个学科的四选一单选题，曾被视为智商金标准，如今各家得分普遍在 88%~92% 以上，四选一本身有 25% 蒙对概率，加上数据污染，已难以反映真实能力。
  • GSM8K：小学数学应用题，7B 级的轻量模型也能考到 95 分以上，测不出复杂推理能力。
  • HumanEval / MBPP：单函数 Python 代码测试，只要求写十几行代码，无法反映真实软件工程中跨文件、有依赖关系的开发能力。
  • SWE-bench / SWE-bench Verified：从 Django、SymPy 等 12 个真实开源仓库中抽取的 2294 个真实 Bug，要求模型在几十万行代码里定位并修复问题、跑通全部单元测试。很多在 MMLU 上考 90 分的模型，在 SWE-bench 上得分不到 15%；即使是 Claude 3.5/3.7 Sonnet 也只能做到 40%~60% 左右。
  • GAIA：由 Meta 和 Hugging Face 设计，模拟人类高级助理在电脑前的真实工作，需要组合网页搜索、阅读长篇 PDF、操作 Excel，考验的是耐心与长程规划。
  • GDPVal：不再看做对几道题，而是直接算经济账，对比人类完成同类工作的薪资与 AI 推理成本，计算真实的投入产出比。

要评估自演进 Agent 的真正能力，必须建立一套面向长周期复杂环境与真实经济价值的新度量衡。

二、 长程难度断崖

在《Measuring AI Ability to Complete Long Tasks》（2025）中，研究者首次按人类完成时间给任务分级： 

Task Horizon Taxonomy:
  • Tier 1 (Flash Tasks):   人类专家可在 1-5 分钟内解决（如单函数编写、概念解释）
  • Tier 2 (Short Tasks):   人类专家耗时 15-30 分钟（如编写单个单元测试模块、简单爬虫）
  • Tier 3 (Medium Tasks):  人类专家耗时 1-2 小时（如重构模块接口、修复回归测试错误）
  • Tier 4 (Long Tasks):    人类专家耗时 4-8 小时以上（如完成端到端全栈功能开发、系统迁移）

实测数据显示出一条陡峭的成功率断崖：Tier 1 任务上前沿模型成功率高达 92.4%，Tier 2 骤降到 51.2%，Tier 3 暴跌至 14.8%，到了 Tier 4，当前最顶尖 Agent 的成功率也跌破 3.5%。

长任务的三个死亡陷阱

  • 过早宣告完工：超过 60% 的 Tier 4 任务失败并非因为模型死机，而是模型刚改完一处无关紧要的代码，就自信地宣布"已完成整个系统重构"，提前终止了推理循环。
  • 上下文漂移：与环境交互超过 40 个轮次后，模型的长注意力机制出现不可逆的稀释，开始频繁忘记最初设定的约束条件。
  • 死循环重试：遇到难以解决的异常时，缺乏重规划能力的 Agent 会陷入"报错→原地重试→再报错"的循环，直到耗尽 Token 预算。

三、 GDPVal：以真实经济价值衡量

GDPVal（Evaluating AI Model Performance on Real-World Economically Valuable Tasks, 2025）不再统计模型答对了多少道题，而是把测试用例与真实 GDP 贡献的核心行业岗位挂钩：半导体行业的 Verilog/RTL 模块编写与审查、金融投行基于招股说明书构建的 LBO/DCF 财务估值模型、生命科学中 RNA-seq 数据的生物信息学分析、企业法务的跨国并购反垄断审查等。

其核心指标是：

$$\text{Economic ROI} = \frac{\text{Human Labor Value Equivalent}}{\text{Agent Inference \& Tool API Cost} \times (1 / \text{Success Rate})}$$

分子是人类专家完成同一工作的市场价值（比如投行分析师做一份复杂财务模型收费 500 美元），分母是 AI 调用 API 的单次成本乘以因失败而产生的重试次数（如单次成本 2 美元、成功率仅 20%，平均重试 5 次即耗资 10 美元）。只有当任务成功率突破临界点、重试成本大幅降低，AI 替代人类劳动的经济 ROI 才会真正显现。

四、 大模型裁判的偏差

讲座后半部分对工业界普遍依赖的"大模型当裁判（LLM-as-a-Judge）"做法提出了批判。大规模盲测量化出四种系统性偏差：

  • 字数偏见：面对一份 50 字的简洁回答和一份 500 字的空洞长文，LLM 裁判有超过 78% 的概率把更高分数给长文。
  • 自相迎合：用 GPT 系列模型当裁判，它会系统性地给 GPT 生成的文本打出比 Claude 或开源模型高约 15% 的分数；反之亦然。
  • 位置偏见：仅仅调换两份答案的先后顺序，裁判判决翻转的概率高达 24%。
  • 谄媚综合征：如果提问暗示"这是一位天才学者的新颖观点"，裁判模型的评分标准会明显放宽。

这说明用一个大模型评判另一个大模型，若缺乏外部沙盒的确定性接地，最终只会演化为两个模型在词藻上的互吹。代码的退出码、单元测试的断言、形式化证明器的内核反馈，才是自演进 Agent 值得信赖的终极裁判。
